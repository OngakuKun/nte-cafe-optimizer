How it works

01

Set the frame

Choose your café count, the active trend and whether Hotori's Cat Decor is on.

02

Mark your roster

Flag owned characters (level 1 or higher counts) and owned dishes on the card pages.

03

Run the optimizer

The C core checks the combinations and shows the best result with all bonuses included.

04

Save or share

Export your config from Settings, import it elsewhere, or keep using the same desktop binary.

Get started

With Docker

docker compose up -d --build
# UI at http://localhost:18423

Compose keeps the shared config in a named volume, so your roster survives rebuilds.

From source

git clone --recurse-submodules <repo-url>
./build.sh Debug
./build/app/nte-cafe-app

Open the UI through the app server — the page bindings need the backend, not just the HTML files.

Full requirements, environment variables and deployment notes are in the README ↗.
